# 💜 Private Couple Chat — (छिपा हुआ प्राइवेट चैट ऐप)

रोमांटिक डार्क-थीम वाला प्राइवेट कपल चैट — छिपा हुआ आइकन, दो एक्सेस कोड,
मेमोरी-ओनली मैसेजिंग, और ऑडियो/वीडियो कॉल UI। **कोई डेटाबेस नहीं, कोई सेव नहीं।**

## ✨ फीचर्स
- 🔒 **Hidden Auth** — सादा "My Notes" डिकॉय पेज, कोने में लगभग अदृश्य 💜 आइकन → पासवर्ड गेट
- 💬 **रियल-टाइम चैट** — BroadcastChannel से दो टैब्स में लाइव मैसेज, टाइपिंग इंडिकेटर, ऑनलाइन स्टेटस
- 📞 **कॉल UI** — इनकमिंग/आउटगोइंग कॉल, Accept/Decline, माइक/कैमरा टॉगल, लाइव टाइमर, एंड कॉल
- 🚫 **No Storage** — कोई localStorage/DB/कुकी नहीं; पेज बंद = सब कुछ मिट
- 💕 रोमांटिक डार्क थीम (पर्पल + हार्ट), फ्लोटिंग हार्ट एनिमेशन

## 🔑 एक्सेस कोड (ज़रूर बदल लेना!)
| कोड | यूज़र |
|-----|------|
| `DIL123` | Partner A (Rahul) |
| `JANU456` | Partner B (Priya) |

बदलने के लिए: `index.html` में `CODES` ऑब्जेक्ट ढूँढो।

## ▶️ लोकल डेमो (2 मिनट में)
1. इस फोल्डर में टर्मिनल खोलो:
   ```bash
   cd couple-chat-app
   python3 -m http.server 8000
   ```
2. ब्राउज़र में **दो टैब** खोलो: `http://localhost:8000`
   - टैब 1 → छिपे 💜 आइकन पर क्लिक → `DIL123`
   - टैब 2 → छिपे 💜 आइकन पर क्लिक → `JANU456`
3. चैट करो, टाइपिंग देखो, कॉल बटन दबाओ!

> माइक/कैमरा के लिए `localhost` या `HTTPS` ज़रूरी है (getUserMedia की शर्त)।
> दोनों टैब एक ही ब्राउज़र में होने चाहिए (BroadcastChannel की सीमा)।

## 🌐 फ्री होस्टिंग
यह सिर्फ एक static फाइल है — Netlify Drop / GitHub Pages / Vercel पर
`index.html` ड्रैग-एंड-ड्रॉप करो, बस। (HTTPS अपने-आप मिलेगा, कैमरा भी चलेगा।)

## ⚠️ डेमो की सीमा (ईमानदार नोट)
- यह **लोकल डेमो** है: सिग्नलिंग BroadcastChannel से होती है, इसलिए दोनों पार्टनर
  के दो **अलग-अलग डिवाइस** कनेक्ट नहीं होंगे।
- **अलग-अलग डिवाइस** के लिए अगला स्टेप: छोटा Node.js + WebSocket सिग्नलिंग सर्वर
  (मैसेज सिर्फ रिले, कभी डिस्क पर नहीं) + WebRTC का पूरा कनेक्शन।
- छिपा आइकन सिर्फ UI छिपाता है; असली सुरक्षा = HTTPS + स्ट्रॉन्ग कोड + (चाहो तो E2E encryption)।
- कुछ नेटवर्क पर WebRTC के लिए TURN सर्वर चाहिए होगा।

## 🗺️ रोडमैप
1. ✅ लोकल डेमो (यह फाइल)
2. ⬜ Node.js + `ws` WebSocket रिले सर्वर (in-memory, zero-DB)
3. ⬜ पूरा WebRTC पीयर-टू-पीयर कनेक्शन (STUN/TURN)
4. ⬜ (ऑप्शनल) E2E एन्क्रिप्शन — सर्वर भी मैसेज न पढ़ सके
